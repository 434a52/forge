# portfolio

A bespoke personal **showcase site** — the curated front door to the projects (links, diagrams, narrative). Built in the project's own stack (Vue/Vite) and, as the libraries land, **dogfoods them**: localised via `l10n`, accessible via `a11y`, animated diagrams via `etch`. A portfolio built *with* the libraries it showcases — meta-proof by construction.

Top-of-stack consumer. Two-phase: start simple (links + diagrams) for early presence; evolve to the dogfooded version as the stack exists.

Design: `./DESIGN.md`. Status: skeleton.
