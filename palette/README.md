# palette

The **design-tokens** layer — canonical design values (colour, spacing, type, motion) as source data, generated via `c5n` into typed, cross-target outputs (CSS custom properties + typed TS constants + …). The shared design foundation the whole front-end draws from: `lattice` (components), `etch` (graphics), `scribe` (email/PDF), `portfolio`.

Base layer, and a **`c5n` consumer** — tokens are canonical data → codegen'd, exactly c5n's job, demonstrating it beyond domain data. Theming = swap token sets.

Design: `./DESIGN.md`. Status: skeleton.
