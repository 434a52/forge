# l10n

Cross-language **localisation** library (C# + TS) — verified conformance, on-device (no API call), tree-shakable, typed. Builds on `f8n` (identity/money) and is generated by `c5n`. Locale-aware format/parse, `{arg:hint}` interpolation, plurals to Welsh, inline formatting, and an AI-translate + human-gate pipeline.

Design: `./DESIGN.md`, `./inline-formatting.md`. Status: design.
