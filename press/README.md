# press

The **render service** — a deployable **Node** process that hosts **Playwright** and turns components into final output: `scribe`'s email HTML + PDF, and `etch`'s SVG → PNG. Called over HTTP by the (C#) business-logic backends with data → ready-formed artifacts, so no consumer spins up Node/Playwright itself.

The one **running-service** member of the stack (the rest are libraries + a static site). Consumes `etch` + `scribe`; HTTP contract DTOs generated by `c5n` (C# ↔ TS, conformant).

Design: `./DESIGN.md`. Status: skeleton.
