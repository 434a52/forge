# lattice

A **Vue component library** — accessible (`a11y`), localised (`l10n`), token-driven (`palette`) UI components. Deliberately **curated, not comprehensive**: the differentiator is the DNA — codegen-native design tokens + accessible-by-construction + localised — not breadth. Fills the gap between `a11y` (accessibility primitives) and the apps (which need real components).

Mid-layer; consumes `palette` + `a11y` + `l10n` (+ `etch` graphics); consumed by `portfolio` and the apps.

Design: `./DESIGN.md`. Status: skeleton.
